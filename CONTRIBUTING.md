# Contributing to CampingDiscoveries

Thank you for your interest in contributing to CampingDiscoveries! We welcome contributions from everyone. Whether it's fixing a bug, suggesting a new feature, or improving documentation, your help is appreciated.

## How to Contribute

### 1. Reporting Bugs
If you find a bug or something that isn't working as expected:
*   **Search for existing issues:** Please check if the issue has already been reported.
*   **Create a new issue:** If not found, open a new issue. Please provide a clear description of the problem, your environment (OS, versions), and steps to reproduce the issue.

### 2. Suggesting Features
Have an idea to make this project better?
*   Open an issue and describe the feature, how it helps, and why it should be added.

### 3. Submitting Pull Requests
If you want to contribute code:
1.  **Fork** the repository.
2.  Create a new **branch** for your changes.
3.  Implement your changes and test them thoroughly.
4.  Submit a **Pull Request (PR)** against the main branch. Please explain what your changes do.

## Code of Conduct
Please note that this project is released with a **Contributor Code of Conduct**. By participating in this project, you agree to abide by its terms. We are committed to fostering a welcoming and safe environment for all contributors.
